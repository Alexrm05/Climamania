Frontend desktop (JavaFX)

Requisitos

- Java 17 o superior.
- Gradle instalado.

Creacion del proyecto

- El proyecto JavaFX ya esta creado en:
  admin_panel/frontend-desktop/AdminPanelClimamaniaFx

Ejecucion

- En la carpeta del proyecto:
  gradle run

Notas

- La app es de escritorio y multiplataforma.
- Si quieres, puedo eliminar el script init_maui.ps1.
