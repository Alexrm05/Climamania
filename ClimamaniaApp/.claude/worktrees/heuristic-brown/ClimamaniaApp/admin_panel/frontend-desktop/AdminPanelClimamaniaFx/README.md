Admin Panel Desktop (JavaFX)

Requisitos

- Java 25.
- Gradle instalado (o usa tu wrapper si lo agregas luego).

Ejecucion

- En la carpeta del proyecto:
  gradle run

Configuracion

- Base URL del backend en ApiClient.java.
- Login via POST /admin/login.php.

Notas

- UI inicial con Login y panel principal.
- Disenada para personalizacion con CSS de JavaFX.
